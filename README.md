# MOVIE KOMBAT

Первый этап. Angular-прототип с двумя демонстрационными списками по 16 фильмов, сценами INTRO → ROULETTE → VS → WINNER → RESULT и локальной историей последних 100 битв.

## Запуск

Понадобится Node.js 24 и pnpm.

```sh
pnpm install
pnpm start
```

Откройте http://localhost:4200. Стрелки перемещают фокус, Enter или OK подтверждает выбор и пропускает текущую анимацию до результата. Escape, Backspace или поддерживаемый браузером сигнал Back возвращает на арену либо завершает анимацию.

```sh
pnpm typecheck
pnpm build
pnpm test
```

Статическая сборка находится в dist/movie-kombat/browser. Демонстрационные метаданные заданы локально. Доступные изображения загружаются с CDN TMDB, а для остальных фильмов и при ошибках загрузки показываются карточки с названием. Интерфейс и движок работают без ключа API. Звук синтезируется через Web Audio, сцены анимируются через CSS.

Каталог, редактирование списков, облачная синхронизация, публикация и интеграции с видеосервисами относятся к следующим этапам. Сигналы пульта обрабатываются на уровне браузера. Для LG и Media Station X требуется проверка на устройстве и отдельная проверка способа запуска.
