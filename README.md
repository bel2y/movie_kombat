# MOVIE KOMBAT

Откройте index.html двойным щелчком. Для запуска не нужны сервер, сборка и установка пакетов. Для публикации на статическом хостинге достаточно index.html и папки src.

Стрелки перемещают фокус. Enter или OK подтверждает выбор и пропускает анимацию. Escape, Backspace или сигнал Back возвращает на арену либо завершает анимацию.

Два демонстрационных списка содержат по 16 фильмов. Последние 100 битв сохраняются там, где браузер разрешает LocalStorage. Доступные изображения загружаются с CDN TMDB. При ошибке остаётся карточка с названием.

Тесты движка запускаются командой `node --test` из корня проекта. Совместимость с LG и Media Station X требует проверки на устройстве.
