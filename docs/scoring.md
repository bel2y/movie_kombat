# Расчёт победителя, версия 2

Соперники выбираются равновероятно из доступных фильмов каждого игрока.

- Желание D = (N − rank)/(N − 1); при N=1 D=1. N — исходная длина списка, rank — исходная позиция, выбывание фильмов их не меняет.
- Рейтинг R = (v × r + 500 × 6.5)/(v + 500)/10. r и v — оценка TMDB и число голосов. 6.5 — выбранный нейтральный prior, не измеренное среднее TMDB; 500 — параметр сглаживания. Без достоверной оценки R=0.65.
- Бонус L = min(поражения, 5)/5. Счётчик ведётся отдельно для каждого игрока и фильма. Совпадения фильмов и выбор из одного списка поражениями не считаются.
- Сила S = 0.60D + 0.25R + 0.15L.
- P(A) = 0.15 + 0.70/(1 + exp(−5 × (S(A) − S(B)))). Победитель определяется одним случайным числом. При одинаковых силах шанс 50%; при любых силах остаётся между 15% и 85%.

Счётчики сохраняются в localStorage movie-kombat.losses.v1. При первом запуске восстанавливаются из имеющейся истории (не более сохранённых 100 записей). Будущие поражения сохраняются независимо от ограничения истории. Старые результаты не пересчитываются. Новый результат содержит formulaVersion и рассчитанные компоненты score.

Рейтинги: src/tmdb-ratings.js — датированный снимок публичного JSON-LD TMDB с URL источника для каждого фильма. Обновление: node scripts/update-tmdb-ratings.cjs. Ключей API нет, приложение не обращается к TMDB за оценками во время битвы. Скрипт заменяет снимок только после успешного получения всех оценок. При изменении списка нужно обновить снимок; для новых фильмов без оценки применяется prior.

Внутренние ID Ронала и Пережить Рождество сохранены ради истории; tmdbId задаёт исправленные внешние привязки.
